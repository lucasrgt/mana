# mana_flow

Headless deterministic step-by-step guided flow (`ManaFlowController<T>`, `ManaFlowStep<T>`, `ManaFlowScope<T>`) for Flutter apps built with Mana.

Powers zero-AI, zero-latency conversational creation flows ("chatzinho guiado"), onboarding wizards, and multi-step forms with conditional step skipping (`skipIf`), per-step validation, clickable answered summaries, and jump-back editing.
