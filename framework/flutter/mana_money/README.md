# mana_money

Headless currency formatting, exact integer minor-unit (`cents`) money values, independent currency scoping (`ManaCurrencyScope`), and live right-to-left cent-growth `ManaCurrencyInputFormatter` for Mana Flutter apps.

Decouples display/input currency (`BRL`, `USD`, `EUR`, or custom ISO currencies) from UI language so users can freely run any locale with any currency.
